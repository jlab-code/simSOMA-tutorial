# simSOMA tutorial

A step-by-step introduction to [simSOMA](https://github.com/jlab-code/simSOMA), the cell-lineage
simulator of somatic mutations in plants. About 45 minutes; every command is tested.

**Read it here:** [simSOMA_tutorial.md](simSOMA_tutorial.md) (renders on GitHub), or download
[simSOMA_tutorial.html](simSOMA_tutorial.html) and open it in a browser.

Contents: install and first run · describe your own tree · read and plot the results ·
sequencing reads from layered organs · trees from terrestrial laser scans · larger runs ·
reference and troubleshooting.

Written for simSOMA 0.2.1 or later.
